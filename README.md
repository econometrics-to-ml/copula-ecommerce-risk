Прогнозирование роста продаж компаний e-commerce с учётом идиосинкразического риска

Исследовательский проект по оценке системных рисков с использованием ансамбля копул.

О проекте

Данный проект демонстрирует полный цикл анализа и прогнозирования: от предобработки данных и кластеризации до построения и валидации сложной статистической модели. Основная цель: разработать алгоритм для более точного прогноза роста продаж компании, учитывающий скрытые взаимосвязи между конкурентами (идиосинкразический риск).

Методология

В основе лежит применение ансамбля копул (copula ensemble): метода/, позволяющий моделировать нелинейные зависимости и хвостовые риски, которые не улавливаются стандартными регрессионными моделями.

Ключевые этапы:

1. Сбор и предобработка данных: Очистка и интеграция финансовых показателей компаний из разных источников.
2. Кластерный анализ (K-means): Разделение компаний на кластеры по уровню активов и выручки.
3. Сетевой анализ: Построение графа взаимосвязей между компаниями на основе их финансовых метрик.
4. Моделирование: Сравнение 12 типов копул и выбор лучшей модели.
5. Кросс-валидация: Оценка стабильности и качества модели.

Главный результат

Лучшая модель (копула Клейтона-Гамбеля) показала коэффициент детерминации R? = 73%, что говорит о высокой предсказательной силе подхода.
